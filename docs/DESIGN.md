# 디자인 가이드

화면은 사용자 목업(podiumtimer2 다크 톤)을 따른다. 흰 Primary 버튼, 시스템 글꼴, 늦음 빨강·빠름 파랑은 유지한다(ADR-017). 판정은 의미 색 배지로 키운다(ADR-018). 랜딩은 움직이는 미리보기와 그림으로 핵심 장면을 보여주고, 노트북에서는 최대 1200px로 넓힌다(ADR-019).

## 디자인 원칙
1. **멀리서 한눈에 읽혀야 한다.** 타이머 화면의 주인공은 숫자 하나(현재 구간 남은 시간)다. 단상에 둔 폰을 1m 떨어져서 봐도 읽히고, 직전 구간이 늦었는지 빨랐는지 색과 글자로 바로 보여야 한다.
2. **색은 의미가 있을 때만 쓴다.** 늦음 빨강, 빠름 파랑, 그 외는 무채색. 버튼·링크도 무채색이다. 색이 보이면 페이스 정보다(에러 문구와 MOCK 배지만 예외).
3. **도구처럼 보여야 한다.** 발표 직전에 바로 쓰는 조작 패널. 보여주기 위한 그림은 랜딩에만 두고, 랜딩도 실제 화면 모양과 의미 색으로만 그린다(움직이는 미리보기, 비교 그림, 그림 있는 기능 카드).
4. **발표 중의 실수는 되돌릴 수 있어야 한다.** 조작 영역은 크게, [되돌리기]는 진행 중 항상 보이게, 종료는 한 번 더 눌러야 되게 한다.
5. **폰이 기준이다.** 360px 너비에서 먼저 맞추고, `md`(768px) 이상에서는 목록·기록·요금제·랜딩이 두 열로, `lg`(1024px) 이상에서는 최대 1200px로 넓어지고 목록은 세 열이 된다. 노트북 전체 화면에서 폰 화면처럼 가운데에 좁게 붙어 보이면 안 된다.

## 색상
다크 테마 고정. 토큰은 `src/app/globals.css`의 `@theme`에 있다.

| 토큰 | 값 | 용도 |
|------|------|------|
| `surface` | `#0a0b0d` | 페이지 배경, 입력 칸 배경 |
| `card` | `#16181c` | 카드·모달, Secondary 버튼 |
| `fill` | `#1f2228` | 칩, 아이콘 버튼, 아이콘 배경, 안내 박스 |
| `line` | `#2a2d33` | 경계선, 입력 칸 테두리, 남은 타임라인 블록 |
| `soft` | `#a8acb3` | 보조 글자(캡션, 라벨, 다음 구간) |
| `muted` | `#7c828a` | 비활성, 푸터 |
| 흰색 | `#fff` / `neutral-50` | 주 글자, 타이머 숫자, Primary 버튼 |

### 데이터/시맨틱 색상
| 용도 | 값 |
|------|------|
| 늦음 (구간 차이 > +1초, 남은 시간 마이너스) | `text-red-400` / 막대 `bg-red-400` |
| 빠름 (구간 차이 < −1초) | `text-blue-400` / 막대 `bg-blue-400` |
| 정시 (반올림한 차이 1초 이하) | `text-neutral-300` |
| 판정 배지 (`verdict`) | 늦음 `bg-red-400/15 text-red-400`, 빠름 `bg-blue-400/15 text-blue-400`, 정시 `bg-white/10 text-neutral-300` (`verdictTone`) |
| 랜딩 헤드라인의 "빨랐는지"·"늦었는지." | `text-blue-400` · `text-red-400` (문장은 하나로 읽힌다) |
| 랜딩 비교 그림의 구간 막대 | 늦음 `bg-red-400`, 빠름 `bg-blue-400`, 정시 `bg-[#6b717b]`. 보통 타이머 막대는 계획 `bg-[#4a4f57]` + 넘친 시간 `bg-red-400` |
| 에러 문구, 입력 오류 테두리 | `text-red-400`, `border-red-400` |
| MOCK 모드 배지 | `bg-amber-500/15 text-amber-300 border border-amber-500/40` |

- 판정은 **항상 색과 글자를 함께** 쓴다 ("0:12 늦음", "0:08 빠름", "정시"). 색만으로 구분하지 않는다. 부호 표기(`+0:12`)는 쓰지 않는다.
- 타이머 화면 배경은 칠하지 않는다. 색은 직전 결과의 판정 배지, 마이너스가 된 남은 시간, 결과·평균 표의 차이 칸(굵게), 평균 막대, 기록 줄의 전체 차이 배지에만 쓴다.
- 배지는 진행·시청 화면의 직전 구간 판정, 랜딩(미리보기·비교 그림·기능 카드), 기록 줄에 쓴다. 표 안에서는 칸이 좁고 배지 바탕이 대비를 낮추므로 글자 색만 쓴다.

## 컴포넌트
공통 모양은 `globals.css`의 `@layer components` 클래스로 쓴다. 컴포넌트에 같은 클래스 묶음을 다시 적지 않는다.

| 클래스 | 모양 |
|------|------|
| `btn btn-primary` | 알약, 흰 바탕 검은 글자, 높이 44px (`btn-lg` 56px) |
| `btn btn-secondary` | 알약, `card` 바탕 흰 글자. 카드·확인 모달 안에서는 `fill` 바탕(버튼으로 보이게). 비활성이면 카드 바탕(`muted` 글자가 `fill` 위에서 대비 4.1이라) |
| `btn-text` | 배경 없는 `soft` 글자 (타이머 삭제, 기록 삭제, 30일권 구매) |
| `icon-btn` | 44px 원, `fill` 바탕. 아이콘만 있을 때 `aria-label`과 `title`을 단다 |
| `card` | 24px 모서리, `card` 바탕, 테두리 없음, 안쪽 여백 20px |
| `chip` | 높이 28px 알약, `fill` 바탕, 12px 굵은 글자 (진행 `3 / 6`, 플랜, 접속자) |
| `plate` | 44px 원 아이콘 배경 (랜딩 기능, 시청자 안내) |
| `field` | 높이 48px, 12px 모서리, `line` 테두리, 포커스 시 2px 밝은 테두리 |
| `verdict` | 높이 28px 알약 판정 배지, 14px 굵은 글자. 진행 화면은 `verdict-lg`(36px, 18px 글자, `md` 40px·20px) |
| `notice` | 16px 모서리 `fill` 박스: 정보 아이콘 + 문구 + [30일권 보기] |
| `spinner` | 28px 회전 원. 시청자 대기실과 결제 반영 중에만 쓴다 |
| `data-table` | 결과·평균 표. 숫자 오른쪽 정렬, 첫 열 왼쪽 정렬, `line` 구분선 |

- 터치 대상은 최소 44×44px. 포커스는 `focus-ring`(`ring-2 ring-neutral-400`).
- 위쪽 바(`AppBar`): 왼쪽에 서비스 이름(홈 링크) 또는 [뒤로] 원형 버튼 + 페이지 제목(h1), 오른쪽에 화면별 동작(플랜 칩, 30일권 구매, 로그아웃 아이콘).
- 확인(타이머 삭제, 기록 삭제, 발표 중단)은 화면 안 모달 `ConfirmDialog`로 한다. 제목·설명·[취소]·[확인] 순서, 열리면 [취소]에 포커스, Esc로 닫는다.
- 한도·인원 안내는 모달이 아니라 화면 안의 `LimitNotice`로 보여준다.

### 타임라인 바
- 차트 라이브러리 없이 `div`로 그린다. 높이 10px, 블록 사이 3px, 블록 모서리 4px, 글자 라벨 없음.
- 진행 화면, 시작 전·대기실 구간 카드, 목록 카드(구간 구성 개요)에 쓴다.
- 블록 너비는 계획 시간 비율(`flex-grow`). 끝난 구간 `#4a4f57`, 현재 구간 `#6b717b`, 남은 구간 `line`.
- 진행 위치에 흰 세로 막대(4×20px) 하나. 현재 구간을 넘겨 쓰면 그 블록 끝에서 멈춘다.
- 시작 전 개요(`done`)는 모든 블록을 끝난 색으로, 막대 없이 그린다.
- 늦음·빠름 색을 쓰지 않는다. 계획 대비 위치 마커는 없다.
- 랜딩 비교 그림의 구간 막대는 타임라인 바가 아니다. 끝난 발표의 결과라서 판정 색을 쓴다.

### 평균 차이 막대그래프
- 차트 라이브러리 없이 `div` 너비(%)로 그린다. 줄마다 `구간 이름 | 막대 | 차이 값(굵게)` 세 칸. 막대는 높이 16px, 기준선 반대쪽 끝만 둥글다.
- 가운데 세로 기준선. 늦음은 오른쪽으로 빨강, 빠름은 왼쪽으로 파랑, 정시는 막대 없음. 아래에 "← 빠름 / 늦음 →" 축 글자.
- 막대 길이는 가장 큰 |평균 차이|를 반쪽 폭의 100%로 맞춘다. 값은 "0:12 늦음" 표기.

## 레이아웃
- 관리 화면: 위쪽 바 + `page`(최대 960px, `lg` 이상 1200px: 목록·기록·요금제·랜딩) 또는 `page page-narrow`(모든 너비에서 최대 560px: 편집·시작 전·결과·시청자·결제·약관). 좌우 여백 20px(`md` 32px), 요소 사이 24px(`md` 32px).
- 위쪽 바는 본문과 같은 최대 폭·좌우 여백을 써서 서비스 이름·[뒤로]의 왼쪽 선이 본문과 맞는다. 좁은 화면은 `AppBar narrow`(560px).
- 넓은 화면 배치: 목록 카드 `md` 2열 → `lg` 3열. 기록은 `md` 평균 | 기록 두 열, `lg` 이상 3 : 2. 요금제 카드 두 장은 넓은 화면에서도 960px 안에 둔다. 랜딩은 아래 "랜딩".
- 타이머·시청자 진행 화면: 화면 전체(`h-dvh`), 스크롤 없음, 위쪽 바는 경계선 아래로 구분. 내용은 왼쪽 정렬, 최대 1100px.
- 하단 푸터: 모든 화면(진행 화면 제외)에 `개인정보처리방침 · 이용약관 · 문의 이메일 주소`, 가운데 정렬 13px.
- 아래 고정 바: 시작 전 화면의 [시작]과 조작 안내는 `sticky bottom-0`으로 화면 아래에 붙는다. `surface` 바탕, 위에 `line` 경계선(`md` 이상은 없음). MOCK 배지가 있으면 `--badge-space`만큼 위로 비켜 선다.

## 타이포그래피
글꼴은 시스템 글꼴을 쓴다 (`-apple-system, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`). 외부 웹폰트를 불러오지 않는다. 시간 숫자는 모두 `tabular-nums`. 한글 제목은 `break-keep`으로 어절 단위로 줄을 바꾼다.

| 용도 | 스타일 |
|------|--------|
| 현재 구간 남은 시간 | `text-[min(30vw,200px)]` (`md` `min(17vw,200px)`) `font-medium tabular-nums leading-none tracking-[-0.04em]` |
| 랜딩 헤드라인 (`hero`) | 36px → `md` 52px → `xl` 68px, 굵기 400, 음수 자간 |
| 랜딩 영역 제목 (`display`) | 28px → `md` 36px → `lg` 44px, 굵기 400, 음수 자간, `text-balance` |
| 페이지 제목·현재 구간 이름 (`title`) | 32px, 굵기 400, 자간 -0.4px |
| 카드 제목·위쪽 바 제목 (`heading`) | 18px 굵게 |
| 라벨 (`label`) | 16px 굵게 |
| 본문 | 14px |
| 캡션 (`caption`) | 13px `soft` |
| 직전 구간 줄 | 16px(`md` 18px) `soft` 라벨 + `verdict-lg` 배지 |
| 전체 남은 시간 | 18px `tabular-nums` (라벨은 14px `soft`) |

시간 표기: `m:ss`(예: `1:42`, `12:05`, `-0:05`). 구간 차이는 `0:12 늦음`, `0:08 빠름`, `정시`.

서비스 이름은 `Podium Timer`로 쓴다. 로고 없이 17px 굵은 흰 글자로만 표시한다.

## 화면별 구성

### 타이머 화면 (발표자, `/timers/[id]/run`)
```
┌──────────────────────────────────┐
│ [3 / 7] [👥 3/3]       (↶) (■)  │ ← 위쪽 바: 탭해도 "다음" 아님
├──────────────────────────────────┤
│ 찬성 입론                        │ ← 현재 구간 이름 (title)
│ 다음 · 반대 입론                 │ ← 다음 구간 (caption)
│                                  │
│ 1:42                             │ ← 현재 구간 남은 시간 (가장 크게)
│                                  │
│ 직전 구간 · 도입 (0:12 늦음)     │ ← 판정 배지만 의미 색
│ ▬▬ ▬▬▬|▬▬ ▬▬▬▬ ▬▬               │ ← 타임라인 바
│ 전체 남은 시간            8:30   │
│                                  │
│   화면 아무 곳이나 탭하면 다음 구간 │ ← 터치 기기 (노트북은 [다음 →] 또는 Space)
└──────────────────────────────────┘
  위쪽 바 아래 전체가 "다음" 탭 영역
```
- 현재 구간 남은 시간이 0을 지나면 숫자 전체가 빨강 "-0:05"로 바뀐다. 전체 남은 시간도 마이너스면 빨강.
- [되돌리기]·[중단]은 원형 아이콘 버튼. [되돌리기]는 되돌릴 '다음'이 있을 때만 활성. [중단]은 확인 모달.
- 아래쪽은 터치 기기(`pointer-coarse`)면 탭 안내 글자, 마우스 기기(`pointer-fine`)면 [다음 →] 버튼(마지막 구간은 [종료 →])과 "또는 Space". 버튼도 0.5초 무시 규칙을 같이 쓴다.
- 마지막 구간에서 [다음]을 누르면 아래쪽에 흰 알약 "한 번 더 누르면 종료"를 3초간 바로 표시한다.
- 공유 중이면 위쪽 바에 접속 칩(사람 아이콘 + `3/3`). 공유 저장이 실패하는 동안은 그 자리에 "공유 연결 끊김" 칩.
- 직전 구간 판정 줄은 `aria-live="polite"`라 구간이 바뀔 때 화면 읽기가 한 번 읽는다. 남은 시간 숫자에는 달지 않는다.
- **시작 전**: 위쪽 바에 타이머 이름. 구간 카드(`SegmentOverview`: "구간 6개" · "합계 14:00", 타임라인 개요, 번호 붙은 구간 목록) → 공유 카드 → 아래 고정 바의 [시작](Primary, 넓게, 큰 버튼)과 조작 안내 캡션. 구간이 0개면 "구간을 추가해야 시작할 수 있어요" + [편집](Primary)만 보이고 공유 카드는 없다.
- 공유 카드: 링크 전 [공유 링크 만들기], 링크 후 `/s/코드` 상자 + [복사](→ "복사됨"), "접속 2/3명 (발표자 포함)", "나 (발표자)"·닉네임 칩. 자리가 가득 차면 안내 박스 "자리가 가득 찼어요 · 30일권은 10명까지 함께 볼 수 있어요" + [30일권 보기](무료일 때만).
- **결과**: "발표가 끝났어요", "날짜 · 계획 10:00 / 실제 10:13", 결과 표 카드, "기록에 저장했어요"(공유였다면 "· 다시 하면 새 공유 링크가 필요해요"), 같은 구간 구성의 첫 기록이면 그 아래 "한 번 더 하면 구간별 평균을 볼 수 있어요"(차트 아이콘). [다시 하기](Primary, 넓게, 큰 버튼), 그 아래 두 칸 [기록 보기] [구간 고치기]. 저장이 실패하면 [다시 저장]. 중단 화면도 같은 [다시 하기]다.

### 시청자 화면 (`/s/[code]`)
- 위쪽 바: 서비스 이름, 오른쪽에 내 닉네임. 연결이 끊기면 그 옆에 "연결 끊김" 칩.
- 닉네임 입력: "공유된 타이머" 캡션, 타이머 이름, 닉네임 칸(전에 쓴 값 자동 채움)과 안내, [입장](Primary, 넓게).
- 대기실: "대기실" 캡션, 타이머 이름, 스피너 카드 "발표자가 시작하면 자동으로 시작돼요", 발표자 시작 전과 같은 구간 카드(`SegmentOverview`).
- 진행: 타이머 화면과 같은 구성에서 조작 버튼·접속 칩·탭 안내를 뺀다.
- 종료: 결과 표 + "다음 발표는 발표자가 보내는 새 링크로 볼 수 있어요". 중단·인원 초과·없는 링크: 가운데 원형 아이콘 + 제목 + 할 일 한 줄 ("인원이 가득 찼어요 (3/3)" / "자리가 비면 링크를 다시 열어 주세요", "발표가 중단되었어요" / "발표자가 다시 시작하면 새 링크로 들어와 주세요").

### 결과 표
- 표: 구간 · 계획 · 실제 · 차이 + 마지막 줄 합계(계획·실제). 계획 칸은 `soft`, 차이 칸만 의미 색 + 글자.

### 타이머 목록 (`/timers`)
- 위쪽 바: 플랜 칩("무료" / "30일권 · 11월 25일까지"), [30일권 구매], 로그아웃 아이콘. 30일권 사용자에게 [30일권 구매]는 연장 구매 입구다(PRD: 또 사면 만료일에 30일을 더함). 폰(`sm` 미만)에서는 플랜 칩이 길어 위쪽 바에 자리가 없으므로 30일권 사용자에게만 숨긴다.
- "내 타이머" + [+ 새 타이머 2/3](Secondary — 카드마다 있는 [▶ 시작]만 Primary). 타이머마다 카드: 이름, "6구간 · 합계 10:00", 타임라인 개요, [▶ 시작](Primary) [편집] [기록]. `md` 두 열, `lg` 이상 세 열.
- 처음이면 카드(시계 `plate`) "첫 타이머를 만들어 보세요" + [+ 첫 타이머 만들기](Primary).
- 목록을 읽지 못하면 에러 문구 아래 [다시 시도].

### 타이머 편집 (`/timers/new`, `/timers/[id]`)
- 이름 칸, "구간" + "6 / 10개 · 합계 14:00"(30일권은 한도 없이 개수만), 줄마다 `손잡이 | 이름 | 시간(m:ss, 오른쪽 정렬) | ✕`.
- 시간 칸은 숫자만 적으면 분으로 읽고(`3` → `3:00`), 읽을 수 있는 값이면 칸을 나갈 때 `m:ss`로 바꿔 보여준다.
- 순서 변경은 손잡이를 끌어서 한다. 손잡이에 포커스가 있으면 ↑/↓ 키로도 옮긴다.
- 에러는 그 줄 아래 13px 빨강 한 줄. 검사는 `lib/validation` 스키마로 한다.
- [+ 구간 추가](넓게) → 한도 안내 → [저장](넓게, 큰 버튼). 저장하면 그 자리에 "저장했어요" 카드 + [▶ 바로 리허설 해보기] [목록으로]. 편집이면 맨 아래 [타이머 삭제] 글자 버튼.

### 기록 (`/timers/[id]/records`)
- 위쪽 바 제목 "기록", 타이머 이름 + [▶ 시작]. `md` 이상 평균 | 기록 두 열(`lg` 이상 3 : 2).
- 기록이 2개 이상이면 평균 카드("같은 구간 구성의 기록 N개", 막대그래프, 평균 표). 아니면 "기록이 2개 이상 쌓이면 구간별 평균을 보여줘요".
- 기록 카드(최신순): 시작 일시, "실제 10:13 · 계획 10:00", 기록 전체 차이 배지("0:13 늦음"), 펼침 화살표. 한 번에 하나만 펼치고, 펼친 결과 표 아래 [이 기록 삭제].

### 요금제·결제
- 요금제: 위쪽 바 제목 "요금제" + 플랜 칩, 헤드라인, 30일권/무료 카드(가격, 체크 목록, [30일권 구매 $3.99]·[30일 연장 $3.99] / [지금 쓰는 중]), 아래 연장·환불 안내. 30일권 카드가 먼저(폰 첫 화면에 구매 버튼이 보이게)이고 흰 1px 안쪽 테두리(`ring-white/20`)로 구분한다.
- 결제 확인: 카드 하나. 반영 중은 스피너 + "30일권 반영 중", 늦어지면 시계 아이콘 + "결제는 완료됐어요" + [타이머 목록]. 반영되면 원래 화면으로 바로 돌아간다.

### 랜딩 (`/`)
- 넓이는 `page`(`lg` 이상 최대 1200px). 영역 사이 72px → `lg` 128px. 폰·노트북 모두 ① → ④ 순서다.
- ① 첫 화면: 헤드라인 "구간마다, 계획보다 빨랐는지 늦었는지."("빨랐는지"는 `text-blue-400`, "늦었는지."는 `text-red-400`, 읽는 문장은 하나), 설명, [Google로 시작하기], "무료 · 만 14세 이상 · 계속하면 이용약관과 개인정보처리방침에 동의하게 돼요". 오른쪽(폰은 아래)에 움직이는 미리보기 카드(`LandingPreview`, 최대 540px). `md` 이상 소개 | 미리보기 두 열, `lg` 이상은 첫 영역이 화면 높이를 채우되 최대 720px이고 내용은 세로 가운데다. 큰 화면(1920×1080 등)에서 첫 영역 아래가 비지 않고 다음 영역 제목이 첫 화면에 걸쳐 보인다.
- 미리보기 카드(스크린 리더에서 숨김, 포커스 가는 요소 없음): 진행 화면과 같은 구성(위쪽 바의 `2 / 6` 칩·되돌리기·중단 모양 + `TimerFace` compact) + 아래 조작 줄. 마우스 기기(`pointer-fine`)는 [다음 →] 모양과 "또는 Space", 터치 기기(`pointer-coarse`)는 "화면 아무 곳이나 탭하면 다음 구간". 진행 화면과 같은 기준이다. 장면은 `lib/demo`의 `demoFrame`이 만들고 시간·판정은 `computeTimer`가 계산한다.
- 재생 장면(9초 반복, 장면 1초 = 250ms): 둘째 구간 "문제 정의"가 0:08부터 줄어 빨간 마이너스가 되고(직전 구간 "인사·소개" 파랑 "0:04 빠름"), -0:11에서 [다음]이 눌려 셋째 구간 "연구 방법" 2:00이 시작되며 배지가 빨강 "0:12 늦음"으로 바뀐다. 눌리는 순간 마우스 기기는 [다음]·Space 모양이 눌리고, 터치 기기는 숫자 옆에 탭 동그라미가 잠깐 보인다.
- 정지 장면(`prefers-reduced-motion`, 서버 렌더와 첫 그림): 셋째 구간 "연구 방법" 1:24, 직전 구간 "문제 정의" 빨강 "0:12 늦음", 전체 남은 시간 7:16.
- ② 비교 그림(`PaceCompare`): 제목 "남은 시간만 보면, 끝나고 나서야 알아요." + 설명. 카드 안 두 줄. "보통 타이머"는 계획(회색) + 넘친 시간(빨강) 막대 하나와 빨강 "-0:13". "Podium Timer"는 실제 시간 비율의 구간 막대 6개(판정 색, 막대 사이 2px 틈 — 같은 판정이 이어져도 구간이 나뉘어 보인다)와 전체 배지 "0:13 늦음", 그 아래 구간 6개(점 + 이름 + 판정 배지, 좁으면 2열·넓으면 한 줄), 마지막에 가장 늦은 두 구간을 짚는 한 줄. 두 막대는 같은 비율(실제 합계 10:13)로 그려 끝이 맞는다.
- ③ 기능 카드 3개(`FeatureCards`, 폰 1열 → `md` 2열 → `lg` 3열): 카드마다 위에 그림 패널(`surface` 바탕, 20px 모서리, 스크린 리더에서 숨김), 아래 원형 아이콘 + 제목 + 설명.
  - 구간별 페이스: 판정이 쌓이는 세로 단계(점 + 구간 이름 + 판정 배지 3줄, 마지막 줄은 진행 중인 넷째 구간).
  - 링크로 공유: 선으로 그린 노트북 1대 + 폰 2대가 미리보기와 같은 남은 시간을 함께 보여주고, 아래 "발표자"·예시 닉네임 2개·접속 `3/3` 칩.
  - 기록과 평균: "같은 구간 구성의 기록 5개" + 예시 평균으로 그린 `AverageDiffChart`.
- ④ 아래 로그인 띠: `card` 안에 "이번 리허설부터 구간마다 확인해 보세요." + "무료 · 만 14세 이상" + 첫 화면과 같은 로그인 버튼(`md` 이상 글과 버튼이 한 줄). 로그인 실패 문구는 누른 버튼 아래에만 보인다.
- 그림은 모두 `div`와 인라인 SVG 아이콘으로 그린다. 사진·일러스트·이미지 파일은 쓰지 않는다. 예시 데이터는 `lib/demo`에 둔다.
- 페이지 메타데이터에 서비스 이름과 한 줄 설명(`MESSAGES.meta.description`)을 둔다. 단톡방 링크 미리보기에 쓰인다.

## 조작 입력
- 타이머 화면에 `touch-action: manipulation`(두 번 탭 확대 방지), `user-select: none`을 건다.
- 터치 기기에서 버튼이 아닌 영역 탭 = [다음]. 시작 지점에서 10px 넘게 움직인 터치는 무시한다.
- 키보드 단축키(`Space`)는 `keydown`에서 처리하고 기본 동작을 막는다. 입력 필드에 포커스가 있거나 확인 모달이 열려 있으면 끈다.
- 0.5초 안의 두 번째 [다음]은 무시한다(탭·Space·버튼 공통). 마지막 구간의 종료 확인도 첫 입력 뒤 0.5초 ~ 3초 사이의 입력만 받는다.

## 애니메이션
- 버튼 hover/active 색 전환(`transition-colors duration-150`)만 허용한다.
- 예외 1: 시청자 대기실과 결제 반영 중의 스피너.
- 예외 2: 랜딩 미리보기 재생(위 "랜딩"). 숫자·배지·진행 위치가 바뀌고, 배지가 바뀔 때 200ms 동안 1.12배에서 제자리로 돌아오며, [다음]·Space 눌림과 탭 동그라미가 장면 2칸(500ms) 동안 보인다. 공유 카드의 숫자도 같은 장면을 따른다. 그 밖의 랜딩 요소는 움직이지 않는다.
- 예외는 모두 `prefers-reduced-motion`이면 멈춘다.
- 타이머·시청자 진행 화면에는 숫자 바뀜과 진행 위치 이동 외에 움직이는 것이 없다. "한 번 더 누르면 종료"도 바로 표시한다.

## 아이콘
- Lucide 선 아이콘 경로를 `components/Icon.tsx`에 인라인 SVG로 둔다(외부 요청 없음). `stroke-width 2`, `currentColor`, 버튼 안 18~20px, 칩 안 14px.
- 원형 배경은 아이콘 버튼(`icon-btn`)과 안내용 아이콘(`plate`)에만 쓴다.

## 문구
- 짧은 존댓말("~해요")로 쓴다. 예: "인원이 가득 찼어요", "무료 한도(타이머 3개)에 도달했어요".
- 모든 문구와 에러 메시지는 `src/lib/messages.ts`에서 가져온다. 컴포넌트에 문구를 직접 쓰지 않는다.
