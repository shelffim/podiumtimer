# UI 디자인 가이드

## 디자인 원칙
1. **멀리서 한눈에 읽혀야 한다.** 타이머 화면의 주인공은 숫자 하나(현재 구간 남은 시간)다. 단상에 둔 폰을 1m 떨어져서 봐도 읽히고, 직전 구간이 늦었는지 빨랐는지 색과 글자로 바로 보여야 한다.
2. **색은 의미가 있을 때만 쓴다.** 늦음 빨강, 빠름 파랑, 그 외는 무채색. 색이 보이면 페이스에 관한 정보다(에러 문구와 MOCK 배지만 예외).
3. **도구처럼 보여야 한다.** 마케팅 장식 없이, 발표 직전에 바로 쓰는 조작 패널. 랜딩도 기능 설명과 화면 미리보기만 둔다.
4. **발표 중의 실수는 되돌릴 수 있어야 한다.** 조작 영역은 크게, [되돌리기]는 진행 중 항상 보이게, 종료는 한 번 더 눌러야 되게 한다.
5. **폰이 기준이다.** 360px 너비에서 먼저 맞추고, 노트북에서는 같은 화면이 넓어질 뿐이다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |
| 빠름에 초록색 | 빨리 끝난 게 "잘했다"는 뜻이 아니다. 서둘렀다는 뜻일 수도 있다 |
| 타이머 숫자에 비례폭 숫자 | 초가 바뀔 때마다 글자 폭이 달라져 화면이 흔들린다 |
| 타이머 화면의 깜빡임·펄스·진행 애니메이션 | 발표자 시선을 뺏는다 |
| 라이트 모드 전환 버튼 | 다크 고정 |

## 색상
다크 테마 고정. 라이트 모드는 만들지 않는다.

### 배경
| 용도 | 값 |
|------|------|
| 페이지 | `#0a0a0a` |
| 패널·카드 | `#141414` |
| 입력 필드 | `bg-neutral-900` (`#171717`) |
| 경계선 | `border-neutral-800` (`#262626`) |

### 텍스트
| 용도 | 값 |
|------|------|
| 주 텍스트, 타이머 숫자 | `text-neutral-50` |
| 본문 | `text-neutral-300` |
| 보조 (다음 구간, 라벨) | `text-neutral-400` |
| 비활성 | `text-neutral-500` |

### 데이터/시맨틱 색상
| 용도 | 값 |
|------|------|
| 늦음 (구간 차이 > +1초, 남은 시간 마이너스) | `#f87171` (`text-red-400`) |
| 빠름 (구간 차이 < −1초) | `#60a5fa` (`text-blue-400`) |
| 정시 (차이 ±1초 이내) | `text-neutral-300` |
| 중립 (대기, 남은 구간) | `#525252` (neutral-600) |
| 에러 문구 | `text-red-400` |
| MOCK 모드 배지 | `bg-amber-500/15 text-amber-300 border border-amber-500/40` |

- 판정은 **항상 색과 글자를 함께** 쓴다 ("0:12 늦음", "0:08 빠름", "정시"). 색만으로 구분하지 않는다.
- 타이머 화면 배경은 칠하지 않는다. 색은 직전 결과 글자, 마이너스가 된 남은 시간, 결과 표의 차이 칸에만 쓴다.

## 컴포넌트
### 패널
```
rounded-md bg-[#141414] border border-neutral-800 p-4
```
목록은 패널을 반복하지 말고 `divide-y divide-neutral-800`로 나눈다.

### 버튼
```
Primary:   h-11 px-4 rounded-md bg-neutral-50 text-neutral-950 font-medium hover:bg-neutral-200
Secondary: h-11 px-4 rounded-md border border-neutral-700 text-neutral-100 hover:bg-neutral-900
Danger:    h-11 px-4 rounded-md border border-red-500/40 text-red-400 hover:bg-red-500/10
Text:      text-neutral-400 hover:text-neutral-200
```
- 터치 대상은 최소 44×44px.
- 아이콘만 있는 버튼에도 `aria-label`을 단다. 타이머 조작 버튼(되돌리기·중단)은 글자 라벨을 함께 쓴다.

### 입력 필드
```
h-11 rounded-md bg-neutral-900 border border-neutral-800 px-3 text-neutral-100
placeholder:text-neutral-500 focus:border-neutral-500 focus:outline-none
```
- 구간 시간은 `m:ss` 형식 하나로 받는다 (예: `3:00`, `12:30`).
- 에러는 필드 아래 `text-sm text-red-400` 한 줄. 검사는 `lib/validation` 스키마로 한다.

### 포커스
```
focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-neutral-400
```

### 안내 (한도 도달, 결제 확인 중, 연결 끊김, 인원 초과)
```
rounded-md border border-neutral-800 bg-neutral-900 px-3 py-2 text-sm text-neutral-300
```
- 모달 대신 화면 안의 안내 박스. 삭제·중단 확인만 브라우저 기본 `confirm()`을 쓴다.

### 타임라인 바
- 차트 라이브러리 없이 `div`로 그린다. 높이 8px, 가로 전체.
- 구간마다 블록 하나, 너비는 계획 시간 비율. 블록 사이 2px 간격. 블록 위에 구간 이름을 `text-xs text-neutral-500`로, 블록 너비를 넘으면 말줄임.
- 끝난 구간 `bg-neutral-500`, 현재 구간은 진행 위치까지 `bg-neutral-50` 나머지 `bg-neutral-800`, 남은 구간 `bg-neutral-800`.
- 진행 위치에 흰 점 하나. 현재 구간을 넘겨 쓰면 그 블록 끝에서 멈춘다.
- 늦음·빠름 색을 쓰지 않는다. 계획 대비 위치 마커는 없다.

### 평균 차이 막대그래프
- 차트 라이브러리 없이 `div` 너비(%)로 그린다.
- 가운데 세로 기준선. 늦음은 오른쪽으로 빨강, 빠름은 왼쪽으로 파랑, 정시는 막대 없음.
- 막대 길이는 가장 큰 |평균 차이|를 100%로 맞춘다. 줄마다 구간 이름과 차이 값("0:12 늦음")을 적는다.

## 레이아웃
- 관리 화면(목록·편집·기록·요금제·계정·약관): 한 열, `max-w-xl mx-auto px-4`, 좌측 정렬.
- 타이머·시청자·대기실 화면: 화면 전체(`h-dvh`), 스크롤 없음. 메인 숫자는 중앙 정렬한다 (이 화면만 예외).
- 간격: 요소 사이 `gap-3`~`gap-4`, 섹션 사이 `space-y-8`.
- 하단 푸터: 관리 화면에 `개인정보처리방침 · 이용약관 · 문의 이메일`, `text-xs text-neutral-500`.

## 타이포그래피
글꼴은 시스템 글꼴을 쓴다 (`-apple-system, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`). 외부 웹폰트를 불러오지 않는다. 시간 숫자는 모두 `tabular-nums`.

| 용도 | 스타일 |
|------|--------|
| 현재 구간 남은 시간 | `text-[clamp(5rem,28vw,12rem)] font-semibold tabular-nums leading-none` |
| 전체 남은 시간 | `text-3xl font-medium tabular-nums text-neutral-300` |
| 현재 구간 이름 | `text-xl font-medium text-neutral-50` |
| 직전 결과, 다음 구간 | `text-base` |
| 페이지 제목 | `text-2xl font-semibold text-neutral-50` |
| 섹션 제목 | `text-sm font-medium text-neutral-400` |
| 본문 | `text-sm text-neutral-300 leading-relaxed` |
| 라벨·보조 | `text-xs text-neutral-400` |

시간 표기: `m:ss`(예: `1:42`, `12:05`, `-0:05`). 구간 차이는 `0:12 늦음`, `0:08 빠름`, `정시`.

## 화면별 구성

### 타이머 화면 (발표자, `/timers/[id]/run`)
```
┌──────────────────────────────────┐
│ 되돌리기      3 / 7    중단  ⛶ │ ← 상단 바: 탭해도 "다음" 아님. ⛶ 전체화면(지원 기기만)
│            접속 3/3              │ ← 공유 중일 때만. 누르면 공유 시트
│                                  │
│           찬성 입론              │ ← 현재 구간 이름
│                                  │
│            1:42                  │ ← 현재 구간 남은 시간 (가장 크게)
│                                  │
│  도입  본론        결론  Q&A     │
│  ████████████●░░░░░░░░░░░░░░░░  │ ← 타임라인 바 (구간 블록 + 진행 위치)
│                                  │
│        전체 8:30 남음            │ ← 전체 남은 시간
│                                  │
│      직전 구간 0:12 늦음         │ ← 직전 결과 (의미 색 + 글자)
│        다음: 반대 입론           │ ← 다음 구간 (보조색)
└──────────────────────────────────┘
  상단 바 아래 전체가 "다음" 탭 영역
```
- 현재 구간 남은 시간이 0을 지나면 숫자 전체가 빨강 "-0:05"로 바뀐다.
- [되돌리기]는 되돌릴 '다음'이 있을 때만 활성.
- 마지막 구간에서 [다음]을 누르면 큰 숫자 아래에 "한 번 더 누르면 종료"를 3초간 표시한다.
- **시작 전**: 타이머 이름, 구간 목록(이름·시간), 전체 시간, [시작](Primary, 넓게), [공유 링크 만들기](Secondary). 공유 중이면 링크와 [복사], "접속 2/3", 접속자 닉네임 목록.
- **공유 시트**: 링크와 [복사], 접속자 닉네임 목록, "접속 n/N". 하단 시트로 열고, 열려 있어도 큰 숫자가 가려지지 않게 한다.
- 인원 초과로 못 들어온 시청자가 있으면 "접속 3/3" 아래 안내 박스: "1명이 인원 초과로 못 들어왔어요"(무료면 "30일권은 10명까지" + [30일권 보기]).
- 공유 저장이 계속 실패하면 "접속" 줄에 "공유 연결 안 됨 · 다시 시도".
- 진행 중에 닫았다 다시 열면: "진행 중인 발표가 있어요" + [이어서 하기](Primary) [중단](Danger).

### 시청자 화면 (`/s/[code]`)
- 닉네임 입력: 타이머 이름, 닉네임 입력 칸(전에 쓴 값 자동 채움), [입장](Primary).
- 대기실: 타이머 이름, 구간 목록, "발표자가 시작하면 자동으로 시작돼요", 접속 인원.
- 진행: 타이머 화면과 같은 구성에서 상단 바의 버튼을 뺀다. 접속 인원은 보이되 누를 수 없다.
- 연결 상태: 끊기면 오른쪽 위에 "연결 끊김"을 작게. 발표자가 Presence에 없으면 상단에 "발표자 연결 끊김 · 타이머는 계속 흘러요".
- 종료: 결과 표. 중단: "발표가 중단되었어요". 인원 초과: "인원이 가득 찼어요 (3/3)". 없는 링크: "존재하지 않는 링크예요".

### 결과 표
- 표: 구간 · 계획 · 실제 · 차이. 차이 칸만 의미 색 + 글자.
- 발표자 결과 화면 아래: [다시 하기](Primary) [기록 보기](Secondary). 기록 저장이 실패하면 [다시 저장].

### 기록 (`/timers/[id]/records`)
- 기록이 2개 이상이면 위에 평균 표(구간 · 계획 · 평균 실제 · 평균 차이)와 평균 차이 막대그래프.
- 아래 기록 목록(최신순, 시작 일시). 누르면 그 자리에서 결과 표가 펼쳐진다. 삭제는 `confirm()`.

## 조작 입력
- 타이머 화면에 `touch-action: manipulation`(두 번 탭 확대 방지), `user-select: none`을 건다.
- 터치 기기에서 버튼이 아닌 영역 탭 = [다음]. 시작 지점에서 10px 넘게 움직인 터치는 무시한다.
- 키보드 단축키(`Space`)는 `keydown`에서 처리하고 기본 동작을 막는다. 입력 필드에 포커스가 있으면 끈다.
- 0.5초 안의 두 번째 [다음]은 무시한다. 마지막 구간의 종료 확인도 첫 입력 뒤 0.5초 ~ 3초 사이의 입력만 받는다.

## 애니메이션
허용하는 것만 쓴다. 그 외 모든 애니메이션 금지. 특히 타이머·시청자 화면에는 숫자 바뀜과 진행 위치 이동 외에 움직이는 것이 없다.
- 버튼 hover/active 색 전환: `transition-colors duration-150`
- "한 번 더 누르면 종료" 표시: fade-in 150ms (`prefers-reduced-motion`이면 바로 표시)

## 아이콘
- SVG 인라인, 24px, `strokeWidth 1.5`, `currentColor`.
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다.

## 문구
- 짧은 존댓말("~해요")로 쓴다. 예: "인원이 가득 찼어요", "무료 한도(타이머 3개)에 도달했어요".
- 모든 문구와 에러 메시지는 `src/lib/messages.ts`에서 가져온다. 컴포넌트에 문구를 직접 쓰지 않는다.
