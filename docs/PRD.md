# PRD: Podium Timer

## 목표
발표·토론을 구간으로 나눠 두고, 발표자가 구간을 넘길 때마다 그 구간이 계획보다 빨랐는지 늦었는지 바로 보여주는 페이스 타이머. 남은 시간만 보여주는 타이머와 달리 "어느 구간에서 시간이 부족하고 어디가 넉넉한지"를 알려준다.

MVP는 프로토타입이다. 로그인 → 타이머 → 공유 → 결제(테스트 모드) → 배포까지 실제로 동작하는 것이 목표이고, 실제 결제와 운영 수준의 견고함은 범위 밖이다.

## 사용자
- **발표자**: 수업·회사 발표를 연습하고 실전에서 페이스를 맞추려는 사람. 폰을 손에 들거나 단상에 두고 조작한다.
- **토론 사회자·타임키퍼**: 발언 순서별 시간을 재는 사람. 토론에서는 이 사람이 타이머를 조작한다.
- **시청자**: 공유 링크로 같은 타이머를 보는 사회자·공동 발표자·청중. 로그인하지 않는다.

## 용어와 계산 규칙
- **타이머**: 이름 + 구간 목록. 계정에 저장된다.
- **구간**: 이름 + 계획 시간(1초 ~ 99분 59초). 토론에서는 발언 하나가 구간 하나다(예: "찬성 입론 3:00").
- **발표**: 타이머를 시작해서 마지막 구간을 넘길 때까지의 한 번의 실행.
- **구간 실제 시간**: 그 구간이 시작된 뒤 "다음"을 누를 때까지 걸린 시간.
- **구간 차이** = 실제 − 계획. 양수면 늦음, 음수면 빠름, 절댓값이 1초 이하면 정시.
- 판정은 구간별로만 한다. 누적 차이는 계산하지도 표시하지도 않는다.
- **현재 구간 남은 시간** = 계획 − 현재 구간 경과. 0을 지나면 마이너스로 늘어난다.
- **전체 남은 시간** = 계획 합계 − 발표 시작 후 경과. 0을 지나면 마이너스로 늘어난다.

## 핵심 기능

### 1. 구간 설정
- 타이머 이름, 구간마다 이름과 시간(분·초)을 입력한다.
- 구간 추가·수정·삭제, 위/아래 버튼으로 순서 변경(드래그 없음).
- 전체 시간 합계를 자동으로 보여준다.
- 계정에 저장한다. 노트북에서 만들고 발표 때 폰에서 실행할 수 있다.
- 타이머 삭제는 확인 창을 거치고, 그 타이머의 기록도 함께 삭제된다.

### 2. 페이스 타이머 실행
- **시작 전**: 구간 목록, "시작" 버튼, "공유 링크 만들기" 버튼, 시청자 수.
- **진행 중 화면**: 현재 구간 남은 시간(가장 크게), 전체 남은 시간(중간), 진행 "3 / 7"과 현재 구간 이름, 직전 구간 결과("0:12 늦음" / "0:08 빠름" / "정시"), 다음 구간 이름. 배치는 UI_GUIDE.md.
- **조작**
  - 시작: "시작" 버튼으로 1구간 시작.
  - 다음: 화면 아무 곳 탭, 노트북은 스페이스바. 마지막 구간에서 누르면 발표 종료.
  - 되돌리기: 직전 "다음"을 취소하고 이전 구간으로 돌아간다. 발표가 종료된 뒤에는 불가.
  - 중단: 확인 창을 거쳐 발표를 끝낸다. 기록은 저장하지 않는다.
  - 일시정지는 없다.
  - 되돌리기·중단 버튼이 있는 상단 바는 탭해도 "다음"으로 넘어가지 않는다.
- 구간 시간이 다 되면 숫자가 빨간색 마이너스로 바뀐다. 소리·진동·미리 경고는 없다.
- 발표 중에는 화면이 꺼지지 않게 한다.
- 새로고침되거나 앱 전환 후 페이지가 다시 열려도 이어서 진행한다.
- 종료되면 같은 화면에 구간별 "계획 / 실제 / 차이" 표를 보여준다.
- 같은 타이머를 여러 기기에서 동시에 실행하는 것은 막지 않는다.

### 3. 기록
- 마지막 구간까지 끝낸 발표만 자동 저장한다. 중단한 발표는 저장하지 않는다.
- 저장 내용: 시작 일시, 구간별 이름·계획 시간·실제 시간. 발표 당시 설정을 복사해 저장하므로 타이머를 고쳐도 옛 기록은 바뀌지 않는다.
- 기록 목록은 최신순. 기록을 누르면 그 자리에서 결과 표가 펼쳐진다. 기록은 하나씩 삭제할 수 있다(확인 창).
- **평균**: 기록이 2개 이상일 때 목록 위에 보여준다. 현재 타이머와 구간 구성(구간 개수와 이름 순서)이 같은 기록만 평균에 넣는다.
  - 표: 구간별 계획 / 평균 실제 / 평균 차이
  - 그래프: 구간별 평균 차이 막대그래프 하나(늦음은 오른쪽 빨강, 빠름은 왼쪽 파랑)
- 기록·평균·그래프는 무료와 30일권 모두 제한 없이 쓴다.

### 4. 공유
- 발표자가 **시작 전에만** "공유 링크 만들기"를 누를 수 있다. 링크를 복사해 카톡 등으로 보낸다.
- 링크 하나는 발표 한 번 전용이다. 다음 발표는 새 링크를 만든다.
- 링크를 만드는 순간 공유 1회가 차감된다(발표를 시작하지 않아도).
- 링크 코드는 추측할 수 없는 무작위 문자열이다.
- **시청자 화면**: 로그인 없이 보기만 한다.
  - 시작 전: "대기 중", 타이머 이름, 구간 목록
  - 진행 중: 발표자와 같은 화면(조작 버튼 없음). 중간에 들어와도 현재 상태부터 보인다.
  - 종료: 결과 표
  - 중단: "발표가 중단되었습니다"
- **시청자 수**: 발표자 화면에만 "3명 보는 중"처럼 작게 보여준다. 지금 접속한 사람 수이고 발표자 본인은 세지 않는다. 시작 전 대기 단계부터 보인다. 시청자 수 제한은 없다.
- **연결이 끊기면**: 양쪽 모두 시간은 계속 흐른다. 시청자 화면 구석에 "연결 끊김"을 작게 표시하고, 다시 연결되면 그사이 바뀐 상태를 반영한다.

### 5. 로그인·계정
- Google 로그인만 지원한다.
- 로그인해야 앱을 쓸 수 있다. 예외: 시작 화면, 공유 시청 화면, 법적 페이지.
- 계정 기능은 로그아웃만. 회원 탈퇴는 문의 이메일로 요청받아 수동 처리한다.

### 6. 요금제와 결제

| | 무료 | 30일권 |
|---|---|---|
| 저장 타이머 | 3개 | 무제한 |
| 타이머당 구간 | 10개 | 30개 |
| 공유 링크 | 평생 3회 | 무제한 |
| 기록·평균·그래프 | 제한 없음 | 제한 없음 |

- **30일권**: $3.99, 1회 결제, 자동 연장 없음. Polar sandbox(테스트 모드)로만 결제한다. 화면은 한국어, 가격은 USD로 표시하고 원화 환산은 표시하지 않는다.
- 이용권이 남아 있을 때 다시 사면 만료일에서 30일 연장한다.
- 한도는 **타이머 새로 만들기, 구간 추가(저장), 공유 링크 만들기** 때만 확인한다. 이용권이 만료돼도 한도를 넘는 기존 타이머·구간은 그대로 실행·수정할 수 있다. 막히는 건 새로 만들기와 구간 추가뿐이다.
- 공유 횟수는 결제 여부와 상관없이 누적으로 센다. 만료 시점에 이미 3회를 넘겼다면 다시 결제해야 공유할 수 있다. 타이머를 삭제해도 차감된 횟수는 돌아오지 않는다.
- 이용권 확인은 공유 링크를 만들 때만 한다. 발표 도중 만료돼도 그 공유는 끝까지 유지된다.
- **한도에 걸리면**: "무료 한도(타이머 3개)에 도달했어요" 같은 안내와 "30일권 보기" 버튼으로 `/pass`에 보낸다. 버튼을 미리 숨기거나 비활성화하지 않는다.
- **결제 완료**: `/timers`로 돌아와 "결제 확인 중…"을 잠깐 보여준 뒤 이용권 상태를 갱신한다.
- **결제 취소·실패**: `/pass`로 돌아온다.
- **환불**: Polar 대시보드에서 수동 처리한다. 이용권 자동 회수는 하지 않는다.
- 결제 내역 화면은 없다. 영수증은 Polar가 이메일로 보낸다.

## 화면

| 주소 | 화면 | 로그인 |
|---|---|---|
| `/` | 서비스 소개 한 줄 + "Google로 시작하기". 로그인 상태면 `/timers`로 이동 | 불필요 |
| `/timers` | 내 타이머 목록. 위: 이용권 상태("무료 · 공유 2회 남음" / "30일권 · 11월 25일까지"), "30일권 구매", 로그아웃. 본문: 타이머 카드(이름·총 시간·구간 수, 실행·수정·기록 버튼), "새 타이머"(무료면 "2/3" 표시) | 필요 |
| `/timers/new`, `/timers/[id]/edit` | 구간 설정 | 필요 |
| `/timers/[id]/run` | 실행: 시작 전 → 진행 → 결과 | 필요 |
| `/timers/[id]/records` | 평균 표·그래프 + 기록 목록 | 필요 |
| `/pass` | 무료/30일권 비교표, $3.99, "구매" → Polar 결제 페이지 | 필요 |
| `/s/[code]` | 공유 시청: 대기 → 진행 → 결과 / 중단 | 불필요 |
| `/privacy`, `/terms` | 개인정보처리방침, 이용약관(환불 규정 포함) | 불필요 |

모든 화면 하단에 개인정보처리방침·이용약관 링크와 문의 이메일을 둔다. 사업자 정보는 표시하지 않는다(사업자 아님).

## MVP 제외 사항
- 일시정지, 클리커 연동, QR 코드
- 토론 전용 기능: 찬/반 팀 구분, 팀별 누적 시간, 작전타임, 토론 형식 템플릿
- 누적(전체) 차이 판정
- 연습/실전 구분, 연습 회차별 추이 그래프, 타이머 복제
- 시청자가 조작하는 기능, 시청자 화면의 시청자 수 표시
- 알림음, 진동, 구간 종료 전 미리 경고
- 라이트 모드, 다국어, 원화 결제
- 이메일 알림(만료 임박 등)
- 환불 자동 처리, 결제 내역 화면, 회원 탈퇴 기능
- 개인 도메인, 개발/운영 환경 분리, 방문자 분석, 에러 모니터링
- 네이티브 앱
