# PRD: Podium Timer

## 목표
발표·토론을 구간으로 나눠 두고, 발표자가 구간을 넘길 때마다 그 구간이 계획보다 빨랐는지 늦었는지 바로 보여주는 페이스 타이머. 남은 시간만 보여주는 타이머와 달리 "어느 구간에서 시간이 부족하고 어디가 넉넉한지"를 알려준다.

MVP는 프로토타입이다. 로그인 → 타이머 → 공유 → 결제(테스트 모드) → 배포까지 실제로 동작하는 것이 목표이고, 실제 결제와 운영 수준의 견고함은 범위 밖이다.

## 사용자
- **발표자**: 수업·회사 발표를 연습하고 실전에서 페이스를 맞추려는 사람. 폰을 손에 들거나 단상에 두고 조작한다.
- **토론 사회자·타임키퍼**: 발언 순서별 시간을 재는 사람. 토론에서는 이 사람이 타이머를 조작한다.
- **시청자**: 공유 링크로 같은 타이머를 보는 사회자·공동 발표자·청중. 로그인하지 않고 닉네임만 입력한다.

## 용어와 계산 규칙
- **타이머**: 이름 + 구간 목록. 계정에 저장된다.
- **구간**: 이름 + 계획 시간(1초 ~ 99분 59초). 토론에서는 발언 하나가 구간 하나다(예: "찬성 입론 3:00").
- **발표**: 타이머를 시작해서 마지막 구간을 넘길 때까지의 한 번의 실행.
- **구간 실제 시간**: 그 구간이 시작된 뒤 "다음"을 누를 때까지 걸린 시간.
- **구간 차이** = 실제 − 계획. 양수면 늦음, 음수면 빠름, 절댓값이 1초 이하면 정시.
- 판정은 구간별로만 한다. 누적 차이는 계산하지도 표시하지도 않는다.
- **현재 구간 남은 시간** = 계획 − 현재 구간 경과. 0을 지나면 마이너스로 늘어난다.
- **전체 남은 시간** = 계획 합계 − 발표 시작 후 경과. 0을 지나면 마이너스로 늘어난다.
- **진행 위치**: 타임라인 바의 마커 위치 = 현재 구간의 계획상 시작 지점 + min(현재 구간 경과, 현재 구간 계획 시간). 현재 구간을 넘겨 쓰면 그 구간 블록 끝에 멈춘다. 계획 대비 위치는 표시하지 않는다.

## 핵심 기능

### 1. 구간 설정
- 타이머 이름, 구간마다 이름과 시간(`m:ss` 한 칸)을 입력한다.
- 구간 추가·수정·삭제, 위/아래 버튼으로 순서 변경(드래그 없음).
- 전체 시간 합계를 자동으로 보여준다.
- 계정에 저장한다. 노트북에서 만들고 발표 때 폰에서 실행할 수 있다.
- 타이머 삭제는 확인 창을 거치고, 그 타이머의 기록도 함께 삭제된다.

### 2. 페이스 타이머 실행
- **시작 전**: 구간 목록, "시작" 버튼, "공유 링크 만들기" 버튼. 공유 중이면 링크 복사 버튼, 접속자 닉네임 목록, "접속 2/3".
- **진행 중 화면**: 현재 구간 남은 시간(가장 크게), 타임라인 바(구간 블록 + 진행 위치), 전체 남은 시간, 진행 "3 / 7"과 현재 구간 이름, 직전 구간 결과("0:12 늦음" / "0:08 빠름" / "정시"), 다음 구간 이름. 배치는 UI_GUIDE.md.
- **조작**
  - 시작: "시작" 버튼으로 1구간 시작.
  - 다음: 화면 아무 곳 탭, 노트북은 스페이스바.
  - 마지막 구간의 다음: "한 번 더 누르면 종료"를 3초 동안 보여주고, 그사이 다시 누르면 발표를 종료한다. 3초가 지나면 문구가 사라지고 그대로 진행한다.
  - 되돌리기: 직전 "다음"을 취소하고 이전 구간으로 돌아간다. 발표가 종료된 뒤에는 불가.
  - 중단: 확인 창을 거쳐 발표를 끝낸다. 기록은 저장하지 않는다.
  - 일시정지는 없다.
  - 되돌리기·중단 버튼이 있는 상단 바는 탭해도 "다음"으로 넘어가지 않는다.
- **잘못 누름 방지**: 0.5초 안의 두 번째 "다음"은 무시한다(마지막 구간의 종료 확인도 0.5초가 지난 뒤의 탭만 받는다). 손가락이 움직인 스와이프는 탭으로 보지 않는다. 두 번 탭 확대와 텍스트 선택은 막는다.
- 구간 시간이 다 되면 숫자가 빨간색 마이너스로 바뀐다. 소리·진동·미리 경고는 없다.
- 발표 중에는 화면이 꺼지지 않게 한다.
- 새로고침되거나 앱 전환 후 페이지가 다시 열려도 이어서 진행한다.
- 종료되면 같은 화면에 구간별 "계획 / 실제 / 차이" 표를 보여준다.
- 같은 타이머를 여러 기기에서 동시에 실행하는 것은 막지 않는다. 발표 도중 다른 기기로 옮겨 이어가지는 못한다.

### 3. 기록
- 마지막 구간까지 끝낸 발표만 자동 저장한다. 중단한 발표는 저장하지 않는다.
- 저장 내용: 시작 일시, 구간별 이름·계획 시간·실제 시간. 발표 당시 설정을 복사해 저장하므로 타이머를 고쳐도 옛 기록은 바뀌지 않는다.
- 기록 목록은 최신순. 기록을 누르면 그 자리에서 결과 표가 펼쳐진다. 기록은 하나씩 삭제할 수 있다(확인 창).
- **평균**: 기록이 2개 이상일 때 목록 위에 보여준다. 현재 타이머와 구간 구성(구간 개수와 이름 순서)이 같은 기록만 평균에 넣는다.
  - 표: 구간별 계획 / 평균 실제 / 평균 차이
  - 그래프: 구간별 평균 차이 막대그래프 하나(늦음은 오른쪽 빨강, 빠름은 왼쪽 파랑)
- 기록·평균·그래프는 무료와 30일권 모두 제한 없이 쓴다.

### 4. 공유
- 발표자가 **시작 전에만** "공유 링크 만들기"를 누를 수 있다. 링크를 복사해 카톡 등으로 보낸다. QR 코드는 없다.
- 링크 하나는 발표 한 번 전용이다. 다음 발표는 새 링크를 만든다. 링크 만들기 횟수 제한은 없다.
- 링크를 다시 만들거나 특정 시청자를 내보내는 기능은 없다.
- 링크 코드는 추측할 수 없는 무작위 문자열이다.
- 링크를 만들 때 타이머 이름과 구간을 대기 화면용으로 복사하고, "시작"을 누를 때 발표자가 실제로 쓰는 구간으로 덮어쓴다. 링크를 만든 뒤 시작 전에 타이머를 고쳐도 시청자와 발표자가 같은 구간으로 계산한다.
- **시청자 입장**: 로그인 없이 닉네임(1~20자)만 입력한다. 전에 쓴 닉네임은 기기에 저장해 자동으로 채운다. 같은 닉네임도 허용한다.
- **시청자 화면**: 보기만 한다.
  - 대기: "대기 중", 타이머 이름, 구간 목록. 발표자가 시작하면 자동으로 바뀐다.
  - 진행 중: 발표자와 같은 화면(조작 버튼·접속 인원 없음). 중간에 들어와도 현재 상태부터 보인다.
  - 종료: 결과 표
  - 중단: "발표가 중단되었어요"
  - 없는 링크: "존재하지 않는 링크예요"
- **동시 접속 인원**: 발표자를 포함해 무료 3명, 30일권 10명. 한도는 링크를 만들 때의 이용권으로 정하고, 발표 도중 만료돼도 그 공유는 끝까지 유지된다.
  - 발표자 화면에 "접속 2/3"과 접속자 닉네임 목록을 보여준다. 발표자는 기기 수와 상관없이 1명으로 센다.
  - 한도를 넘으면 늦게 들어온 시청자가 "인원이 가득 찼어요 (3/3)" 화면으로 바뀌고 나간다. 발표자 화면에는 "1명이 인원 초과로 못 들어왔어요"를 보여주고, 무료면 "30일권은 10명까지"와 "30일권 보기" 버튼을 함께 보여준다.
  - 탭을 닫거나 오래 끊긴 시청자는 접속자에서 빠진다. 돌아오면 다시 입장하고, 그사이 자리가 찼으면 "인원이 가득 찼어요".
- **연결이 끊기면**: 양쪽 모두 시간은 계속 흐른다. 시청자 화면 구석에 "연결 끊김"을 작게 표시하고, 다시 연결되면 그사이 바뀐 상태를 반영한다. 연결이 살아 있어도 10초마다 최신 상태를 다시 확인한다.

### 5. 로그인·계정
- Google 로그인만 지원한다.
- 로그인해야 앱을 쓸 수 있다. 예외: 시작 화면, 공유 시청 화면, 법적 페이지.
- 계정 기능은 로그아웃만. 회원 탈퇴는 문의 이메일로 요청받아 수동 처리한다.

### 6. 요금제와 결제

| | 무료 | 30일권 |
|---|---|---|
| 저장 타이머 | 3개 | 무제한 |
| 타이머당 구간 | 10개 | 30개 |
| 공유 동시 접속 (발표자 포함) | 3명 | 10명 |
| 공유 링크 만들기 | 제한 없음 | 제한 없음 |
| 기록·평균·그래프 | 제한 없음 | 제한 없음 |

- **30일권**: $3.99, 1회 결제, 자동 연장 없음. Polar sandbox(테스트 모드)로만 결제한다. 화면은 한국어, 가격은 USD로 표시하고 원화 환산은 표시하지 않는다.
- 이용권이 남아 있을 때 다시 사면 만료일에서 30일 연장한다.
- 타이머·구간 한도는 **타이머 새로 만들기(구간 수 포함), 구간 추가(저장)** 때만 확인한다. 이용권이 만료돼도 한도를 넘는 기존 타이머·구간은 그대로 실행·수정할 수 있다. 막히는 건 새로 만들기와 구간 추가뿐이다.
- 동시 접속 한도는 시청자가 들어올 때 화면에서 확인한다(서버에서 강제하지 않음).
- **한도에 걸리면**: "무료 한도(타이머 3개)에 도달했어요" 같은 안내와 "30일권 보기" 버튼으로 `/pass`에 보낸다. 버튼을 미리 숨기거나 비활성화하지 않는다.
- **결제 완료**: `/timers`로 돌아와 "결제 확인 중…"을 잠깐 보여준 뒤 이용권 상태를 갱신한다.
- **결제 취소·실패**: `/pass`로 돌아온다.
- **환불**: Polar 대시보드에서 수동 처리한다. 이용권 자동 회수는 하지 않는다.
- 결제 내역 화면은 없다. 영수증은 Polar가 이메일로 보낸다.

## 화면

| 주소 | 화면 | 로그인 |
|---|---|---|
| `/` | 서비스 소개 한 줄 + "Google로 시작하기". 로그인 상태면 `/timers`로 이동 | 불필요 |
| `/timers` | 내 타이머 목록. 위: 이용권 상태("무료" / "30일권 · 11월 25일까지"), "30일권 구매", 로그아웃. 본문: 타이머 카드(이름·총 시간·구간 수, 실행·수정·기록 버튼), "새 타이머"(무료면 "2/3" 표시) | 필요 |
| `/timers/new`, `/timers/[id]/edit` | 구간 설정 | 필요 |
| `/timers/[id]/run` | 실행: 시작 전 → 진행 → 결과 | 필요 |
| `/timers/[id]/records` | 평균 표·그래프 + 기록 목록 | 필요 |
| `/pass` | 무료/30일권 비교표, $3.99, "구매" → Polar 결제 페이지 | 필요 |
| `/s/[code]` | 공유 시청: 닉네임 입력 → 대기 → 진행 → 결과 / 중단 / 인원 가득 | 불필요 |
| `/privacy`, `/terms` | 개인정보처리방침, 이용약관(환불 규정 포함) | 불필요 |

모든 화면 하단에 개인정보처리방침·이용약관 링크와 문의 이메일을 둔다. 사업자 정보는 표시하지 않는다(사업자 아님).

## 입력 범위
화면과 서버가 같은 스키마로 검사한다.

| 항목 | 범위 |
|---|---|
| 타이머 이름 | 1~60자 |
| 구간 이름 | 1~40자 |
| 구간 시간 | 1초 ~ 99분 59초 |
| 닉네임 | 1~20자. 앞뒤 공백과 보이지 않는 제어 문자 제거 |
| 구간 0개인 타이머 | 저장·시작 불가 |

## MVP 제외 사항
- 일시정지, 클리커 연동, QR 코드
- 공유 링크 다시 만들기, 시청자 내보내기
- 토론 전용 기능: 찬/반 팀 구분, 팀별 누적 시간, 작전타임, 토론 형식 템플릿
- 누적(전체) 차이 판정, 타임라인 바의 계획 대비 위치 표시
- 연습/실전 구분, 연습 회차별 추이 그래프, 타이머 복제, 타이머 템플릿
- 중단한 발표의 기록
- 발표 도중 다른 기기로 옮겨 이어가기
- 시청자가 조작하는 기능, 시청자 화면의 접속 인원 표시
- 알림음, 진동, 구간 종료 전 미리 경고
- 라이트 모드, 다국어, 원화 결제
- 이메일 알림(만료 임박 등)
- 환불 자동 처리, 결제 내역 화면, 회원 탈퇴 기능
- 개인 도메인, 개발/운영 환경 분리, 방문자 분석, 에러 모니터링
- 네이티브 앱
