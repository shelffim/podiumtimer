# 브라우저 테스트 시나리오

브라우저로 앱을 확인할 때마다 이 문서를 기준으로 한다. 유스케이스 6개를 UC1부터 순서대로 돌리고(앞 UC가 만든 데이터를 뒤 UC가 쓴다), 끝나면 6절 "실행 기록"에 한 줄을 남긴다.

- 브라우저 E2E 자동 테스트는 PRD "MVP 제외 사항"이다. 저장소에 테스트 코드를 두지 않고, 이 문서를 따라 손이나 dev-browser 스크립트로 돌린다.
- Claude Code에서는 `/browser-test [UC 번호]`로 돌린다. `browser-tester` 에이전트가 이 문서대로 실행해 결과만 돌려주고, 커맨드가 4절·6절을 갱신한다. 문제는 고치지 않는다.
- 기대 문구는 `src/lib/messages.ts` 기준이다. 문구·화면·흐름을 바꾸면 이 문서의 해당 단계도 같이 고친다.
- 단계 번호(`UC2-5` 등)로 알려진 문제와 실행 기록에서 가리킨다.

### 2.2 터치 탭 흉내
headless 브라우저는 터치 기기가 아니어서 `pointerType: "touch"` 이벤트를 직접 보낸다. `dx`를 주면 손가락이 움직인 스와이프가 된다.

```js
const tap = (page, x, y, dx = 0) => page.evaluate(([x, y, dx]) => {
  const el = document.elementFromPoint(x, y);
  const opt = (cx) => ({ bubbles: true, pointerId: 7, pointerType: "touch", clientX: cx, clientY: y, isPrimary: true });
  el.dispatchEvent(new PointerEvent("pointerdown", opt(x)));
  if (dx) el.dispatchEvent(new PointerEvent("pointermove", opt(x + dx)));
  el.dispatchEvent(new PointerEvent("pointerup", opt(x + dx)));
}, [x, y, dx]);
// 390×844 기준: 본문(숫자) (195, 400), 상단 바 (195, 30)
```

### 2.3 같은 브라우저에서 시청자 여러 명
mock 공유는 localStorage와 BroadcastChannel이라 **같은 브라우저 프로필의 탭끼리만** 된다. 다른 브라우저 컨텍스트나 기기에서는 링크가 "존재하지 않는 링크예요"가 된다.

- 접속자를 구분하는 `clientId`는 탭마다 따로(sessionStorage) 생긴다. 시청자마다 새 탭을 열면 된다.
- 닉네임과 입장 여부(`joined:{코드}`)는 브라우저에 하나만 저장된다. 같은 링크에 한 탭이라도 입장했으면 다음 탭은 저장된 닉네임으로 바로 들어간다. 탭마다 다른 닉네임을 쓰려면 탭을 열기 직전에 `nickname`을 바꾼다.

```js
async function openViewer(name, nickname, url) {
  const page = await browser.getPage(name);
  await page.setViewportSize({ width: 390, height: 844 });
  await host.evaluate((nick) => localStorage.setItem("nickname", nick), nickname);
  await page.goto(url);
  await page.waitForTimeout(1500);
  const enter = page.getByRole("button", { name: "입장" });
  if (await enter.count()) { await enter.click(); await page.waitForTimeout(1500); }
  return page;
}
```

### 2.4 30일권 만료 흉내
mock 주문의 결제 시각을 61일 전으로 옮긴다. 연장 주문까지 함께 옮겨야 만료된다.

```js
await page.evaluate(() => {
  const orders = JSON.parse(localStorage.getItem("mock:orders"));
  const t = Date.now() - 61 * 86400000;
  localStorage.setItem("mock:orders", JSON.stringify(orders.map((o, i) => ({ ...o, paidAt: t + i }))));
});
```

### 2.5 판정 기대값 잡기
판정은 화면에 보이는 반올림한 초로 한다. 반올림한 차이가 1초 이하면 정시라서 "0:01 늦음/빠름"은 나오지 않는다. 0.5초 근처는 반올림이 흔들리므로 기대값은 **계획과 2초 이상 차이 나게** 조작해서 확인한다.

### 2.6 헷갈리기 쉬운 것
- `npm run dev`에는 Next.js 개발 도구 버튼("Open Next.js Dev Tools")이 떠서 `getByRole("button")` 개수에 잡힌다. 시청자 화면의 "버튼 없음"은 `main` 안에서 센다.
- `getComputedStyle(...).color`는 `lab(L a b)`로 나온다. 빨강은 a가 크고(약 +60), 파랑은 b가 크게 음수(약 −57)다.
- 마지막 구간의 Space 두 번은 0.5초 넘게 띄운다. 직전 [다음]과 0.5초 안에 누른 Space는 무시돼서 종료 힌트가 늦게 뜬다.
- UC4-2의 막대는 두 기록의 평균 차이에 달렸다. 반올림해 1초 이하면 "정시"라 막대가 없는 것이 맞다.
